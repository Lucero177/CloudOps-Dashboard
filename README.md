# CloudOps Dashboard
Panel web para planificar y visualizar una solución Cloud en AWS (datos simulados). Práctica integrativa Cloud Foundations, semanas 5 y 6.

## Tecnologías
React, TypeScript, Vite, Tailwind CSS, React Router, Lucide React.

## Instalación y ejecución
```
npm install
npm run dev
```

## Funcionalidades
Dashboard · Planificación Cloud (formulario + tarjetas) · Costos (cálculo mensual/anual y gráfico) · Infraestructura Global · Seguridad (responsabilidad compartida, IAM) · Arquitectura de Red · Catálogo de Servicios AWS con búsqueda y filtro. Responsive y con persistencia en localStorage.
